# 🚀 NEXUS // 3D Personal Business & Full-Stack Technology Website

A futuristic, interactive 3D personal business website built with **Next.js 14**, **React 18**, **TypeScript**, **Tailwind CSS**, **Three.js / React Three Fiber (`@react-three/fiber`, `@react-three/drei`)**, and **Framer Motion**.

---

## ✨ Homepage Flow

`Navbar → 3D Hero → Stats → About → Services → Projects → Tech Stack → Work Process → Why Me → Contact → Footer`

---

## 🛠️ Quick Start

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```

3. **Open in browser:**
   Navigate to [http://localhost:3000](http://localhost:3000)

4. **Production build:**
   ```bash
   npm run build
   npm start
   ```

---

## 🎨 Customizing Your Brand Name & Content

- **Live In-Browser Customizer:** Click the **"Edit Brand"** button in the top navigation bar (or **"Customize Brand"** in the footer) to update your Name, Short Badge, Tagline, Email, and Phone in real time.
- **Static Configuration File:** Edit [`src/data/siteData.ts`](./src/data/siteData.ts) to permanently customize `defaultBrandConfig`, `statsData`, `aboutPillars`, `servicesData`, `projectsData`, `techStackData`, `workProcessData`, and `whyMeData`.
